This distlib was built without its UI

The node is running, and its API answers at /rpc and /events. The web pages were not built before this binary was, so there is nothing to show here yet.

To build them, with Node.js installed:

cd crates/distlib-api/ui
npm ci
npm run build
cd ../../..
cargo build --release

A release build embeds whatever crates/distlib-api/ui/dist holds when it is compiled; a debug build reads that folder while it runs.
